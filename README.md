# 藥看仔細 SeeUrMeds

Chrome 擴充功能。醫師在自己的電腦開「健保雲端查詢系統」的雲端藥歷時，在瀏覽器側欄列出病人這些藥**長什麼樣子**：外觀照、形狀、顏色、刻痕、刻字、尺寸。

病人常說「白色圓圓那顆」，這個工具讓醫師當場對得起來。

0.2.0 起多一個功能：開「檢查與檢驗 → 檢查檢驗結果」時，側欄把**不同院所、不同寫法的同一種檢驗**歸在一起（例如「HbA1c」「09006C醣化血紅素」），由新到舊列出並畫趨勢圖。只整理檢驗數值，不處理影像報告。

## 它做什麼、不做什麼

- 只讀畫面上用藥表格的：藥品名稱、成分名稱、就醫日期、院所名稱、用法用量、給藥日數、藥品用量、主診斷的 ICD-10 碼。
- 檢驗頁只讀檢驗表格的：檢驗項目、檢驗結果、單位、參考值、檢體、檢驗日期、來源院所。
- 不讀病人姓名、身分證號。
- 不存檔、不上傳。藥名與檢驗名稱的比對用的是擴充功能內附的對照表，全部在這台電腦的瀏覽器裡完成。
- 唯一的對外連線：向食藥署網站（`mcp.fda.gov.tw`）下載藥品外觀照。這個連線只帶圖片編號，不帶病人資料；但食藥署的伺服器會知道「這台電腦看了哪幾顆藥的照片」。
- 權限只要求「側欄」，以及在 `medcloud2.nhi.gov.tw`、`medcloud.nhi.gov.tw` 讀取頁面內容。

## 安裝（尚未上架，用「載入未封裝項目」）

1. 下載這個 repo（Code → Download ZIP，解壓縮），或 `git clone`。
2. Chrome 網址列輸入 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選 repo 裡的 `extension` 資料夾。
4. 把「藥看仔細 SeeUrMeds」釘到工具列。

需要 Chrome 116 以上。Edge 也可以用同樣方式載入。

## 使用

1. 照平常方式登入健保雲端查詢系統，查到病人，開「雲端藥歷」。
2. 按工具列的藥丸圖示，右邊會開側欄。
3. 側欄依就醫日期（新到舊）和院所分組，標題列顯示日期、診斷碼（ICD-10）、院所，底下列出每顆藥的外觀。點照片可看原圖。
4. 換病人或換頁後，側欄會自動重讀；沒有更新就按「重新讀取」。

### 看檢驗

1. 開「檢查與檢驗 → 檢查檢驗結果」，側欄會自動換成檢驗畫面（回到雲端藥歷就換回用藥）。
2. 依類別（血糖、血脂、腎功能…）列出每一種檢驗的最新數值、日期和小趨勢圖。超出參考值的標 ↑（紅）或 ↓（藍）。
3. 點一下某個項目，會展開大圖（淺色帶是參考範圍）和每一次的數值、參考值、院所、原本的檢驗名稱。

剛安裝或更新後，要先重新整理健保雲端那一頁。

## 限制

- 用**藥名**比對（雲端藥歷畫面上沒有健保藥品代碼）。對不到的藥會寫「無外觀資料」，不會猜。
- 同一個藥名對到多張許可證時，取許可證字號排序後第一張有外觀照的。
- 食藥署開放資料裡約兩成許可證有外觀照；針劑、外用藥、中藥濃縮製劑大多沒有。
- 只讀目前這一頁顯示的列。雲端藥歷若分頁，換頁後才會讀到下一頁。
- 藥廠改版後外觀可能和照片不同。**請以實物與藥袋為準。**
- 檢驗名稱靠內附字典歸類（各院所寫法不一，沒有統一編碼可用）。字典對不到的名稱不會丟掉，照原名列在「未歸類」，同名的仍會排在一起；也可能歸錯，展開後看得到原本的名稱，**請以健保雲端原始畫面為準**。
- ↑↓ 用的是該筆檢驗所屬院所自己的參考值；參考值分男女或沒寫的，不判斷。
- 不做單位換算。單位不同的數值照樣列出，但不畫進同一張趨勢圖。
- 檢驗也只讀目前這一頁顯示的列；想看更長的趨勢，先在健保雲端把每頁筆數調大或把日期區間拉長。
- 健保署改版網頁後可能讀不到表格，請回報。

## 資料來源

- 健保用藥品項（藥名與許可證字號對應）：衛生福利部中央健康保險署。
- 藥品外觀、許可證資料與外觀照：衛生福利部食品藥物管理署開放資料。

以上依「政府資料開放授權條款－第 1 版」使用。對照表 `extension/data/drugs.json` 由維護者定期重建（`tools/build_data.py`），檔內 `built` 是建立日期。

檢驗名稱字典 `extension/data/labs.json` 是維護者自己寫的比對規則（`tools/build_labs.py`），不含任何病人資料。發現歸錯或缺漏，歡迎開 issue 或直接改規則。

## 開發

```
node test/core.test.js          # 藥名比對、檢驗名稱歸類
python3 tools/build_labs.py     # 改了檢驗名稱規則後重建 labs.json
python3 -m http.server 8799     # 再開 http://127.0.0.1:8799/test/harness.html 看側欄（假資料；檢驗加 ?f=fixture_labs.html）
```

`test/` 裡的表格都是假資料，沒有真實病人。

## 聲明

本工具與健保署、食藥署無關，是輔助辨識用的參考資訊，不是醫療器材，不能取代藥師與醫師的核對。
